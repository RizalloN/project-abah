   ├─ Set via XAMPP control panel
   ├─ Or via MySQL command: mysqladmin -u root password "R!zalloN5588"
   └─ Then update .env with same password

3. phpMyAdmin shows error
   ├─ Clear browser cache
   ├─ Try incognito mode
   ├─ Try from different URL: http://localhost/admin-db-secret-a1b2c3
   └─ Check config.inc.php for syntax

4. Port 80 already in use
   ├─ Find what's using it: netstat -ano | findstr :80
   ├─ Kill the process: taskkill /PID [PID] /F
   └─ Then restart Apache

5. Permission denied errors
   ├─ Run Apache as Administrator
   ├─ Check folder permissions are correct
   ├─ Verify path in config is correct
   └─ Check user account has read/write access
