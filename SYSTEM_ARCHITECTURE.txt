================================================================================
                         CRITICAL COMPONENTS
================================================================================

1. DuckDNS Client (PC Anda)
   ├─ Status: MUST be ALWAYS RUNNING
   ├─ Frequency: Check & update setiap 5-10 menit
   ├─ Failure: Jika crash, IP tidak update
   └─ Setup: Auto-start di Startup folder

2. Router with Port Forwarding
   ├─ Setup: Forward port 80 to 192.168.1.100:80
   ├─ Status: Berjalan otomatis
   └─ Note: Jangan matikan, jangan reset

3. Apache Web Server
   ├─ Status: Harus running setiap saat
   ├─ Port: Listen 0.0.0.0:80
   ├─ Auto-Start: Enable di Task Scheduler
   └─ Service: httpd.exe

4. Network Connectivity
   ├─ Internet: Must be connected
   ├─ ISP: Don't block port 80 (or setup alt port)
   └─ Firewall: Allow httpd.exe outbound
